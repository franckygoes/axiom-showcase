# Public boundary

## Included

- bounded architectural description;
- verified release metadata;
- aggregate test counts;
- synthetic scenario outcomes;
- integrity manifest for this showcase;
- safety and limitation statements.

## Excluded

- private runtime source code;
- private policy files and prompts;
- private plugins and Skill implementations;
- secrets, local paths, personal data and customer data;
- Git history from the engineering repository;
- any material from `axiom-meta-hackathon`;
- live trading, collection, publication or other external actions.

## Verification meaning

The public bundle verifies the integrity and internal consistency of the
published evidence. The underlying private implementation was tested separately
with the canonical release verifier. Because its source is not distributed,
this showcase does not pretend to offer independent source-level reproduction.

That distinction is deliberate: evidence is published without silently turning
the private engineering platform into an open-source release.
